# java-racingcar-precourse

## 기능 목록
- [x] 자동차의 이름과 시도할 횟수를 입력 받음
  - 자동차의 이름은 중복될 수 없으며, 공백을 입력하거나 연속된 쉼표를 입력할 수 없음.
  - 시도할 횟수는 1에서 30 사이의 정수를 입력해야 함.
- [x] 입력 받은 자동차의 이름을 쉼표`,`를 기준으로 구분
- [x] 무작위 값을 이용해여 해당 자동차의 전진 여부 파악
  - 0에서 9 사이의 무작위 값을 구한 후 4 이상일 경우 전진.
  - 무작위 값은 `camp.nextstep.edu.missionutils.Randoms`의 `pickNumberInRange()`를 활용.
- [x] 모든 자동차에 대해 무작위 값을 구한 이후 자동차의 상황을 출력
  - 자동차의 이름과 전진 상태를 출력.
  - 출력 예시) `pobi : -`
- [x] 우승자 파악 후 출력
  - 만약 우승자가 여러 명일 경우 쉼표`,`를 이용하여 구분.
  - 출력 예시) `최종 우승자 : pobi, jun`
- [x] 예외 처리
  - 자동차의 이름 혹은 시도할 횟수에 잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시킨 후 애플리케이션을 종료.
- [x] 테스트 코드 작성 및 확인
  - 정리한 기능 목록이 정상적으로 작동하는지 테스트 코드로 확인.
