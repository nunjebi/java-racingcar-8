# java-racingcar-precourse

## 구현 예정 목록

- [x] 자동차 이름 및 시도할 횟수 입력
- [x] 입력받은 자동차 이름을 쉼표`,`를 기준으로 구분
- [x] 무작위 값을 이용하여 해당 자동차의 전진 여부 파악
  - 0에서 9 사이에서 무작위 값을 구한 후 4 이상일 경우 전진.
  - 무작위 값은 `camp.nextstep.edu.missionutils.Randoms`의 `pickNumberInRange()`를 활용.
- [x] 시도된 횟수마다 차량의 상황을 출력
  - 출력 예시) `pobi : -`
  - 자동차의 이름과 전진 상태를 출력.
- [ ] 우승자 파악
- [ ] 우승자 출력
  - 출력 예시) `최종 우승자 : pobi, jun`
  - 만약 우승자가 여러 명일 경우 쉼표`,`를 이용하여 구분.
- [ ] 예외 처리
  - 잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시킨 후 애플리케이션을 종료.

## 요구 사항

- indent depth는 최대 2.
  -> 메서드 분리하기.
- 3항 연산자 사용 금지.
- 함수(또는 메서드)가 한 가지 일만 하도록 최대한 작게 만들기.
- JUnit 5와 AssertJ를 이용하여 기능 목록이 정상적으로 작동하는지 테스트 코드로 확인.
